## App access and review path

All core game features are accessible without an account, payment, invitation from an existing user or credentials. From the home screen enter a synthetic nickname, keep Solo selected, create a room and ready/start. To review online mode, select Online, create a new room and tap Fill bots, Ready, Start. For two human clients choose 1v1, open the same release on another device (or the production website), enter a different nickname, select Online and Join Room, and enter the host's displayed code. Both clients ready up. The host starts. Draw from stock, select a card and discard. Rotate a compact screen to landscape at the table. The host can choose No timer when setting up a review room. Always generate a new room; there is no persistent reviewer account or code.
