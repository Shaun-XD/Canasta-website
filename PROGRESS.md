## Release checks

- **Clean build.** Node 22, JDK 21, SDK 36, Gradle 8.14.7. `npm ci`, `npm run android:bundle`, `npm run lint`, `npm test`, `npm run build`, and `cd android && ./gradlew :app:lintRelease`. All 248 tests passed, including the backend bridge. Web lint passed, Android lint reported zero findings, and the dependency audit returned zero known findings. Check `release/qa/build-checks.json`, `bundle-verification.json`, and the logs beside the AAB.
- **Exact installation.** bundletool 1.18.3 generated the universal APK from the AAB in the table. `adb -s SERIAL install PATH_TO_APK` installed it after uninstalling the previous app on CanastaOpen. `adb -s SERIAL install -r PATH_TO_APK` tested the upgrade path on CardsPhone and restored an existing game. Build artifacts and full logs are local under `artifacts/android-release/5d6188c/`. Their checksums and release source are in Git. The upload-signed artifact and Play install/pre-launch report await the publisher.
- **Foldable emulator.** Android 16/API 36 (Pixel Fold family hinge profile, OnePlus Open display dimensions). While playing an online 1v1 match, Android switched between the inner and cover displays, rotated both, preserved the same room, seat, cards and turn, and allowed touch reordering. The cover rotation prompt and 182/168/93 px inner portrait/inner landscape/outer landscape stock controls followed the shipped handheld layout. Cold offline solo exercised opening-discard pickup, melding and bot return. Background/resume and a true airplane-mode disconnect/rejoin preserved state. The remote client received the next draw and discard. Measurements, test commands and Android screenshots are in `release/qa/` and `artifacts/android-release/device/5d6188c/`.
- **Production doubles.** Two independent clients plus teammate and opponent bots. The installed app exercised Fill/Remove/Refill, Ready/Start, stock draw and discard, timer pause/resume and return of control to the human. Both bots drew, melded twice and discarded on separate events roughly 1.4 seconds apart. Visible cards travelled from both seats in the recording. The final installed phone build used End round at empty stock, scored 285 and −135, then dealt round 2 with the same totals. [Bot footage](release/qa/installed-bot-turns.webp) · [Observed score transitions](release/qa/android-doubles-score-5d6188c.json).
- **Coverage limits.** Physical Android device coverage: none. OnePlus Open–sized tests used a real folding emulator with distinct displays. Separate browser-only comparisons for phone, unfolded devices, and desktop are in `release/qa/browser-viewport-baseline.jsonl`. CardsPhone showed Android System UI/launcher/Wellbeing unresponsive dialogs during concurrent startup or installation. After recovery the app completed the recorded match. Physical performance, other OEMs and Play delivery remain unverified.
- **Public services.** Web production, production/staging Railway health and the published privacy policy returned HTTP 200. The Android client used its packaged HTTPS origin with the existing production server. No Vercel or Railway release or room reset was applied. The dedicated policy and release branches are the only branches published by this work.
