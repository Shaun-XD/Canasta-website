# Canasta privacy policy

Effective November 19, 2026. This policy covers the Canasta Android game maintained in the Shaun-XD/Canasta-website project.

## Solo games

The game and its artwork are bundled with the app. Your solo display name, cards, moves and score are processed on your device. Solo play does not require registration or an internet connection.

## Online games

When you create or join a room, the app sends the display name you choose, your room and player identifiers, game settings and gameplay actions to the Canasta multiplayer server hosted by Railway. Use a nickname you are comfortable showing to other players. Players in the room see names, seats, teams, readiness, connection status, public card plays and scores. Remaining hands are visible during round review. Anyone you give the room code to may be able to join.

These data are used to run the match, synchronise turns and restore a connection. Room state is held in the game server's memory and cleared when the game server process restarts. Leaving the room or closing the app does not immediately remove that state from the server. Your device keeps the most recent online room and player identifiers for reconnection. Exiting the room through the game or clearing the app's storage removes the local reconnection information.

## Connections and logs

Online gameplay uses encrypted connections. The hosting service processes network information, including IP addresses, timestamps, request paths, response status and client information, to deliver and operate the service. Server logs can include connection identifiers, actions and errors. These logs have a different lifecycle from rooms. Railway's standard log history varies by hosting plan. Its current published windows range from 3 days to 90 days depending on plan. A plan change can make older logs accessible. For details, see [Railway logging](https://docs.railway.com/observability/logs#log-retention).

The game has no advertising or analytics SDK, purchases, chat, or player accounts. It does not request contacts, precise location, microphone or camera access. Opening an external site such as the project's support page makes a separate connection to that site's operator.

## Privacy questions and requests

Contact the Canasta project maintainers through [Canasta project support](https://github.com/Shaun-XD/Canasta-website/issues/new). This is a public tracker. For a private matter, ask for a private reply channel before sending identifying details. Never post a room code, session identifier, IP address or personal contact details there. You can use Android Settings → Apps → Canasta → Storage to clear the game's local data.
